# Backend scaffold

The Express implementation is intentionally pending assignment. `routes/` and `controllers/` reserve the required structure.

The agreed backend task must add package.json (with npm start), an Express entry point, mounted Router, controller functions, a single in-memory state owner, and independent endpoint checks. No game endpoints exist yet.

Use the taught JavaScript ES-module pattern. Install/start instructions will be added with the first implementation PR. Do not copy node_modules into Git.
